# Europe-focused literature sweep: values in European spatial planning (2005–2026)

## Scope and framing
- **Question focus:** how “values” are conceptualized in European spatial planning scholarship, and how/if those value concepts are translated into practical planning tools and implementation.
- **Period target:** 2005–2026.
- **Priority:** peer-reviewed review/theory papers + empirical case studies in Europe.
- **Methods used:** broad web mapping (`web_search`), targeted narrowing, and cross-check with `alpha search` CLI.

## (b) Extracted findings: value conceptualization + practical applicability

### 1) How values are conceptualized
- **Legal-constitutional framing of values:** In Central-East European systems, values are explicitly embedded in planning law, including sustainable development, public interest, environmental and heritage protection; however, legal statement ≠ guaranteed realization in practice [1].
- **Values as multi-type constructs:** VLP work formalizes value typologies (economic, social, ideological, ecological, aesthetic, technical; plus spatially allocated/intangible categories), treating values as explicit planning inputs rather than implicit background norms [2].
- **Values also exist implicitly in planning discourse:** Nordic public-space cases show values can be reconstructed from planning language and representations, not only from formal value statements [4].
- **Planning culture as value carrier (inference):** Comparative literature on planning cultures suggests actors, policy styles, and institutional practices mediate which values become actionable [6]. *(Inference from comparative framing rather than one direct test statement.)*

### 2) Practical applicability (tools, procedures, implementation)
- **Implementation gap is a recurring pattern:** Both legal-value studies and strategic-planning synthesis indicate persistent translation gaps from plan/value statements to implemented outcomes [1][3].
- **Procedural operationalization exists but is demanding:** VLP proposes concrete implementation steps (expert value identification, stakeholder deliberation, synthesis into binding decision, monitoring), implying applicability is feasible when governance capacity and participatory design are strong [2].
- **Trust/negotiation are implementation conditions:** SPlaMI evidence from 21 European urban regions emphasizes trust-building and negotiated governance as prerequisites for implementation continuity [3].
- **Instrument-specific implementation performance varies strongly by country/institution:** Cropland-protection review across 11 Western European countries reports heterogeneous instrument strength and implementation preconditions [5].

### 3) Working synthesis for Europe (2005–2026)
- European spatial-planning scholarship increasingly moves from **normative value declaration** toward **procedural/implementation realism** (deliberation, governance capacity, monitoring), but still reports major execution deficits [1][2][3][5].
- The literature supports a two-level model: **(i) explicit value frameworks** (law, strategic plans, typologies) + **(ii) practice-mediated realization** (institutions, actor coalitions, policy style, implementation instruments) [1][2][3][6]. *(Inference across multiple sources.)*
