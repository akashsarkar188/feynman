# Plan: Values in European Spatial Planning

- **Slug:** `values-european-spatial-planning`
- **Date:** 2026-04-28
- **Objective:** Produce a literature review on how values (normative, social, ecological, economic, democratic) are conceptualized, operationalized, and contested in European spatial planning.

## Scope and key questions

1. What “values” are discussed in European spatial planning literature (e.g., equity, sustainability, growth, heritage, participation, justice, resilience)?
2. How are values embedded in planning doctrines, plans, tools, and evaluation frameworks?
3. How do values differ across scales (EU, national, regional, municipal) and planning systems?
4. What empirical evidence exists on value conflicts/trade-offs in planning decisions?
5. Which methods are used to elicit or evaluate values (participatory methods, MCA, CBA critiques, deliberative planning, geodesign)?
6. What implementation gaps persist between stated values and realized outcomes?

## Source strategy

- **Papers:** alpha + web retrieval of peer-reviewed journals and foundational planning theory papers.
- **Policy/institutional sources:** EU/ESPON/Council of Europe/OECD planning principles where needed for practice framing.
- **Repos/code:** only if specific tools are central to value operationalization claims.

## Time period

- Primary window: 2005–2026 (to capture post-ESDP/territorial cohesion developments)
- Include earlier classics if frequently cited for value frameworks.

4. Evidence from practice and case studies
