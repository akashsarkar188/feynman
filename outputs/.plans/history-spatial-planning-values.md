# Plan: Values in the History of Spatial Planning

- **Date:** 2026-04-29
- **Topic:** values in history of spatial planning
- **Slug:** `history-spatial-planning-values`

## 1) Scope and key questions

### Core research questions
1. How have normative values in spatial planning evolved historically (e.g., order, efficiency, public health, equity, sustainability, participation, resilience, rights)?
2. Which historical eras mark major value shifts in planning thought and practice (industrial/modernist, welfare-state, neoliberal, communicative/collaborative, sustainability/climate eras)?
3. How do key planning traditions differ in value orientation (rational-comprehensive, advocacy, communicative, strategic/spatial, justice-oriented, postcolonial/decolonial critiques)?
4. What value conflicts recur across eras (growth vs equity, technocracy vs democracy, property rights vs collective goods, preservation vs development)?
5. Which regions/authors are overrepresented, and where are historiographic gaps?

### Boundaries
- Primary focus: historical scholarship on spatial/urban/regional planning values.
- Geographic focus: Europe and North America core canon, with global/postcolonial critiques where historically relevant.
- Time frame: foundational texts (late 19th/early 20th century) through 2026 review literature.

## 2) Source strategy
- **Papers/books (primary):** planning theory/history journals, classic books, historiographic reviews.
- **Web (current/reference support):** encyclopedia/library entries, publisher pages, institutional planning history resources.
- **Repos/code:** low relevance; only used if bibliometric datasets or history-of-planning corpora are available.
